# SkyDiao Mod

## 这是什么?

自从2026/2/23前后开始, Hypixel在Skyblock彻底扼杀了1.8.9版本客户端, 未来只能使用高版本客户端加入Skyblock

因此, 小沙雕非常的无奈. 重新制作了一个SkyDiao Mod来为Skyblock打造功能.

从2026/2/23 8:00:00开始, 这个mod仅有irc一个功能, 但是后面会逐步迁移各个Skyblock功能.

1.8.9的Hypixel Helper Mod下载: https://xiaoshadiao.club/hhdownload

# 安装

需要Minecraft 1.21.10的最新版Fabric加载器, 安装Fabric后将mod拖入mods文件夹食用即可.
